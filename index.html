PIILOHIPPA

Käynnistä NES30 pitämällä START pohjassa (Android-tila) ja yhdistä se puhelimeen Bluetoothilla. Paina sitten aloitusnappia ja laita puhelin VR-laseihin.

Ilman laseja: hiiri = katse (klikkaa ruutua), WASD/nuolet = liiku, Q/E = käänny, F = A-nappi, välilyönti = hyppy / kiipeä, Shift = juoksu, C = kyykky, R = nollaa katse, Enter = valikko
